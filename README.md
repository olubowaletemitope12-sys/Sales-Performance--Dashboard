Sales Performance Dashboard — Microsoft Excel
Project Overview
 This project presents an interactive Sales Performance Dashboard developed using Microsoft Excel. The dashboard was created to analyze sales revenue, product performance, regional sales, employee performance, payment methods, and order status.
The analysis provides insights that can support better sales monitoring and business decision-making.
Key Metrics-
* Total Revenue: ₦11.51 million
* Total Quantity Sold: 599
* Number of Employees: 75
Key Findings
1. Food & Beverage recorded the highest product sales, making it the strongest-performing product category, followed by Clothing.
2. The North region recorded the highest overall product sales, while the South and West regions recorded comparatively lower sales.
3. Cash was the most-used payment method, accounting for approximately 44% of total revenue, while Card and Transfer each accounted for approximately 28%.
4. Completed orders significantly exceeded cancelled and pending orders, indicating a high level of successful order fulfillment.
5. Employee sales performance varied considerably, with some employees generating substantially higher revenue than others.
Recommendations
1. Maintain and strengthen the performance of the Food & Beverage category through effective promotions, adequate stock availability, and continued monitoring of customer demand.
2. Improve sales in lower-performing regions, particularly the South and West, by introducing targeted promotions and region-specific sales strategies.
3. Continue providing multiple payment options while maintaining the convenience of cash payments and encouraging the use of electronic payment methods.
4. Investigate cancelled and pending orders to identify possible causes and reduce unsuccessful or delayed transactions.
5. Analyze the strategies used by high-performing employees and apply useful practices to improve the performance of lower-performing employees.
6. Continue monitoring sales, revenue, and order trends to support informed business decisions and identify areas for growth.
Tools Used
* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Excel Dashboard
* Data Cleaning
* Data Analysis
* Data Visualisation
Conclusion
The analysis shows that Food & Beverage and the North region were strong contributors to overall sales performance, while differences in employee performance and regional sales highlight opportunities for improvement. The dashboard provides a clear overview of key sales indicators and can be used to monitor performance and support data-driven decision-making.




Sales Performance Dashboard — Microsoft Power BI
Project Overview
 This project presents an interactive Sales Performance Dashboard developed using Microsoft Power BI. The dashboard analyzes project benefits, regional performance, project phases, project complexity, and performance trends over time.
The analysis provides insights into the factors influencing project performance and highlights areas that require further attention.
Key Findings
1. The North region recorded the highest project benefit, making it the strongest-performing region in terms of project profitability.
2. Project performance peaked in 2022 and declined afterward, indicating a need to investigate the factors contributing to the post-2022 decline.
3. High-complexity projects accounted for the largest share of projects, suggesting that a significant proportion of the projects involved higher levels of complexity.
4. Project activity varied across phases, with Phase 4 having the highest number of projects and Phase 1 having the lowest.
5. Project performance fluctuated across months, with notable increases and decreases throughout the year.
Recommendations
1. Identify and replicate successful practices from the North region in other regions to improve overall project performance.
2. Investigate the decline in project performance after 2022 to identify the operational or business factors responsible and develop strategies to improve future performance.
3. Strengthen the management of high-complexity projects through effective planning, resource allocation, and continuous monitoring.
4. Review project performance across different phases to identify bottlenecks and improve project progression from planning through implementation.
5. Monitor monthly and yearly project-benefit trends regularly to identify performance changes early and support timely decision-making.
Tools Used
* Microsoft Power BI
* Power Query
* Data Cleaning
* Data Transformation
* Data Analysis
* Data Visualization
* Interactive Dashboards
Conclusion
The analysis shows that the North region was the strongest contributor to project benefits, while overall project performance experienced a decline after 2022. The high proportion of complex projects also highlights the importance of effective project planning and management. The dashboard provides an interactive view of these trends and supports data-driven decision-making.
